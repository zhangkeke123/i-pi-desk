# 启动闪屏 + 墨点 Logo 设计

**日期**：2026-10-14  
**状态**：已批准  
**范围**：每次冷启动闪屏（非首次欢迎页）+ 灵动墨点 logo

## 目标

- 每次启动：上方 logo，下方进度条，从约 1% 到 100% 后进入工作台
- Logo：墨点脉冲（青绿圆点 + 细环呼吸），小尺寸有静态降级
- 进度：混合（真阶段锚点 + 阶段内缓动），最短展示 ≈ 800ms

## 结构

居中纵排：`InkLogo` → `i-pi-desk` → 细进度条 → 百分比。  
无按钮、无长文案；`bootError` 时展示错误（沿用现有）。

## 进度阶段

| 阶段 | 目标 | 触发 |
|------|------|------|
| 起步 | 15% | 闪屏挂载 / init 开始 |
| 设置 | 40% | 开始拉取 settings/providers/… |
| 会话 | 75% | Promise.all 完成 |
| 收尾 | 90% | `booted === true` |
| 关门 | 100% | 已 booted 且展示 ≥ 800ms 后冲刺 |

到 100% 后卸盖层，露出 AEI 工作台。

## 非目标

- 首次欢迎引导页（本次不做）
- Electron 安装包 `.ico` 重打包（可先落地 SVG 组件与资源，图标管线另开）

## 实现要点

- `InkLogo`：SVG + CSS 呼吸动画
- `SplashScreen`：盖层 + 缓动进度
- `app-store.init`：写入 `bootTarget`
- 纯函数 `approachBootProgress` 单测覆盖
